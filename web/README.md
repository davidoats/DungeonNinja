# Dungeon Ninja – Web Recreation

This is a browser recreation of the supplied `Dungeon Ninja.jar`.

## Run

No server is required. Extract the folder and double-click `index.html`.

Modern browsers may block music until you press the **Play** button; the game deliberately starts audio only after that click.

## Controls

- **WASD** or **Arrow keys**: move
- **Mouse**: aim
- **Left mouse**: katana attack / combo
- **Hold V**: zoom out

## Recreated systems

- Original 15×15 maps and tile art
- Original player sprites and object sprites
- Original katana artwork and three-hit combo timing
- Zombie enemies with grid-based A* pathfinding
- Training dummy, enemy health bars, damage flashes and floating damage numbers
- Key/door interactions and level loading
- Original music and sound effects
